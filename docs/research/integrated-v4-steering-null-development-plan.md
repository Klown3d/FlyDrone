# EPG→Delta7→PFL3 steering-null development plan

## Purpose

This diagnostic asks whether the implemented EPG→Delta7→PFL3 partner
arrangement matters when PFN→hDeltaB and all engineering layers remain intact.
It is development work and cannot support a confirmatory claim.

## Controlled rewiring

Five deterministic null seeds rewire EPG→Delta7 and Delta7→PFL3 separately.
Within each presynaptic source-side block, every null preserves binary row and
column degrees and every postsynaptic neuron's exact raw nonzero-weight
multiset. Weighted column sums and exact partner identities are not preserved.

Each null receives one algebraic global phase alignment to the intact composite
PFL3 transfer. That alignment is computed before flight simulation and does
not use arrival outcomes. Residual nonuniform phase errors are not corrected.

## Development cases

The diagnostic deliberately reuses the 12 cases from the earlier PFN→hDeltaB
development suite. They are suitable for implementation debugging but are not
unseen. Any prospective steering-attribution gate must use new scenarios,
target bearings, initial headings and null seeds fixed before execution.

## Decision after development

Proceed to a prospective gate only if the intact controller remains functional,
all nulls satisfy their preservation audits, and the distribution shows enough
separation to justify the cost of at least 20 new rewired networks. A weak or
mixed result must be reported as such rather than tuned away.
